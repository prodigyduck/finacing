## User Scenarios & Testing *(mandatory)*

### User Story 1 - 전일 대비 증감 표시 (Priority: P1)

사용자는 대시보드를 열었을 때 각 계좌의 전일 대비 증감이 🔺🔻 아이콘과 색상으로 명확하게 표시되는 것을 보고, 자산 변화를 직관적으로 이해할 수 있어야 한다.

**Why this priority**: 사용자가 가장 많이 찾는 정보는 "오늘 얼마나 변했는가"이다. 이것이 가장 중요한 사용자 요구이다.

**Independent Test**: 증감 표시만 추가하여 사용자가 변화를 더 빨리 이해하는지 테스트할 수 있다.

**Acceptance Scenarios**:

1. **Given** 대시보드 페이지에 접속했을 때, **When** 각 계좌 카드를 보면, **Then** 전일 대비 증감이 🔺+0.1억 또는 🔻-0.05억 형식으로 표시된다
2. **Given** 증감을 보고 있을 때, **When** 색상을 확인하면, **Then** 증가는 빨간색, 감소는 파란색으로 구분되어 표시된다
3. **Given** 변동이 없는 계좌를 보고 있을 때, **When** 증감을 확인하면, **Then** "변동 없음" 또는 "±0억"으로 표시된다

---

### User Story 2 - 기간 선택 기능 (Priority: P2)

사용자는 대시보드에서 일별/주별/월별 탭을 선택하여 원하는 기간의 데이터를 확인할 수 있어야 한다.

**Why this priority**: 기간 선택은 데이터 분석에 유용하지만, 기본적인 일별보기가 먼저 제공되어야 한다.

**Independent Test**: 기간 선택 탭만 추가하여 사용자가 기간을 전환하며 데이터를 확인하는지 테스트할 수 있다.

**Acceptance Scenarios**:

1. **Given** 대시보드를 보고 있을 때, **When** 기간 탭(일별/주별/월별) 중 하나를 선택하면, **Then** 그래프와 데이터가 해당 기간에 맞게 표시된다
2. **Given** 주별 탭을 선택했을 때, **When** 데이터를 확인하면, **Then** 각 주의 평균 또는 마지막 날짜 기준으로 집계된 데이터가 표시된다
3. **Given** 월별 탭을 선택했을 때, **When** 데이터를 확인하면, **Then** 각 월의 마지막 날짜 기준으로 집계된 데이터가 표시된다

---

### User Story 3 - 요약 정보 상단 표시 (Priority: P3)

사용자는 대시보드 상단에 총 자산과 전일 대비 변화가 요약되어 표시되는 것을 보고, 스크롤하지 않고도 핵심 정보를 한눈에 파악할 수 있어야 한다.

**Why this priority**: 요약 정보는 편리하지만, 계좌별 정보가 먼저 제공되어야 한다.

**Independent Test**: 상단 요약 바만 추가하여 사용자가 핵심 정보를 더 빨리 확인하는지 테스트할 수 있다.

**Acceptance Scenarios**:

1. **Given** 대시보드를 열었을 때, **When** 페이지 최상단을 보면, **Then** "총 자산: 5.57억 (전일 대비 🔺 +0.03억)" 형식으로 요약이 표시된다
2. **Given** 요약을 보고 있을 때, **When** 총 자산을 클릭하면, **Then** 전체 계좌 상세로 스크롤 이동한다
3. **Given** 요약을 보고 있을 때, **When** 전일 대비 변화를 확인하면, **Then** 색상과 아이콘으로 증감이 직관적으로 표시된다

---

### Edge Cases

- **첫 번째 날짜인 경우**: "전일 대비"가 없을 때 어떻게 표시하는가? ("-" 또는 "데이터 없음")
- **데이터가 없는 기간을 선택한 경우**: 빈 상태 또는 "해당 기간 데이터 없음" 메시지 표시
- **증감액이 매우 작은 경우**: 0.01억 미만인 경우 어떻게 표시하는가? (소수점 둘째자리까지 또는 "미미한 변화")
- **증감액이 매우 큰 경우**: 1억 이상인 경우 어떻게 표시하는가? (그대로 표시 또는 단위 축약)
- **색맹 사용자인 경우**: 색상 외에 다른 시각적 구분 요소가 제공되는가? (아이콘, 텍스트 라벨)

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 각 계좌의 전일 대비 증감을 계산하여 표시해야 한다
- **FR-002**: 시스템은 증감을 🔺🔻 아이콘과 함께 색상(증가: 빨간색, 감소: 파란색)으로 표시해야 한다
- **FR-003**: 시스템은 일별/주별/월별 기간 선택 탭을 제공해야 한다
- **FR-004**: 시스템은 선택한 기간에 맞게 데이터를 집계하여 표시해야 한다
- **FR-005**: 시스템은 페이지 상단에 총 자산과 전일 대비 변화를 요약해야 한다
- **FR-006**: 시스템은 첫 번째 날짜의 경우 "전일 대비"를 "-" 또는 "데이터 없음"으로 표시해야 한다
- **FR-007**: 시스템은 0.01억 미만의 변동을 소수점 둘째자리까지 표시해야 한다
- **FR-008**: 시스템은 데이터가 없는 기간을 선택한 경우 "해당 기간 데이터 없음"을 표시해야 한다

### Key Entities

- **증감 정보**: 계좌별 전일 대비 증감액, 증감률, 색상, 아이콘
- **기간 필터**: 일별/주별/월별 선택 및 해당 기간 데이터 집계
- **요약 바**: 총 자산, 전일 대비 변화, 클릭 가능한 영역

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사용자의 95%가 증감 정보를 "명확하다" 또는 "매우 명확하다"고 평가한다
- **SC-002**: 사용자가 전일 대비 변화를 찾는 데 걸리는 시간이 50% 이상 단축된다 (기존 평균 10초 → 5초 이하)
- **SC-003**: 사용자의 80%가 기간 선택 기능을 "유용하다" 또는 "매우 유용하다"고 평가한다
- **SC-004**: 사용자의 85%가 요약 정보를 "도움이 된다" 또는 "매우 도움이 된다"고 평가한다
- **SC-005**: 색맹 사용자의 70%가 증감 정보를 아이콘과 텍스트만으로도 정확하게 이해한다

## Assumptions

- 전일 대비 비교는 직전 영업일 기준으로 한다
- 주별 집계는 해당 주의 마지막 영업일 기준으로 한다
- 월별 집계는 해당 월의 마지막 영업일 기준으로 한다
- 데이터는 매일 업데이트된다고 가정한다
- 사용자는 일별 보기를 기본으로 사용한다
