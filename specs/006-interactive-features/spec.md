# Feature Specification: Interactive Features

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 그래프 인터랙션 개선 (Priority: P1)

사용자는 계좌별 추이 그래프에서 마우스 오버 시 향상된 툴팁을 확인하고, 계좌 레전드를 클릭하여 특정 계좌를 show/hide할 수 있어야 한다.

**Why this priority**: 그래프는 사용자가 데이터를 탐색하는 주요 수단이며, 기본적인 인터랙션이 필수적이다.

**Independent Test**: 그래프 인터랙션만 추가하여 사용자가 데이터를 더 쉽게 탐색하는지 테스트할 수 있다.

**Acceptance Scenarios**:

1. **Given** 계좌별 추이 그래프를 보고 있을 때, **When** 데이터 포인트에 마우스를 오버하면, **Then** 해당 날짜의 모든 계좌 금액이 툴팁으로 표시된다
2. **Given** 그래프를 보고 있을 때, **When** 특정 계좌의 레전드를 클릭하면, **Then** 해당 계좌가 숨겨지거나 다시 표시된다
3. **Given** 그래프를 보고 있을 때, **When** 마우스 휠로 줌 인/아웃을 하면, **Then** X축 범위가 확대/축소된다

---

### User Story 2 - 계좌 드릴다운 (Priority: P2)

사용자는 계좌 카드를 클릭하여 해당 계좌의 보유 종목 상세 정보와 종목별 변동 차트를 확인할 수 있어야 한다.

**Why this priority**: 드릴다운은 심층 분석에 유용하지만, 기본적인 계좌 보기가 먼저 제공되어야 한다.

**Independent Test**: 드릴다운만 추가하여 사용자가 계좌 상세를 확인하는지 테스트할 수 있다.

**Acceptance Scenarios**:

1. **Given** 대시보드를 보고 있을 때, **When** 특정 계좌 카드를 클릭하면, **Then** 해당 계좌의 보유 종목 리스트와 종목별 변동 차트가 표시된다
2. **Given** 계좌 상세를 보고 있을 때, **When** 뒤로가기 버튼을 클릭하면, **Then** 대시보드 메인 화면으로 돌아간다
3. **Given** 계좌 상세를 보고 있을 때, **When** 종목명을 클릭하면, **Then** 해당 종목의 상세 정보(수량, 평균 단가, 현재가 등)가 표시된다

---

### User Story 3 - 계좌 비교 모드 (Priority: P3)

사용자는 두 계좌를 선택하여 나란히 비교하고, 기간을 설정하여 before/after를 비교할 수 있어야 한다.

**Why this priority**: 비교 모드는 고급 분석 기능이지만, 기본적인 보기가 먼저 제공되어야 한다.

**Independent Test**: 비교 모드만 추가하여 사용자가 두 계좌를 비교하는지 테스트할 수 있다.

**Acceptance Scenarios**:

1. **Given** 대시보드를 보고 있을 때, **When** "비교 모드" 버튼을 클릭하면, **Then** 두 계좌를 선택할 수 있는 UI가 표시된다
2. **Given** 비교 모드에서 두 계좌를 선택했을 때, **When** 비교 결과를 확인하면, **Then** 두 계좌의 그래프가 나란히 표시되고 증감율이 계산된다
3. **Given** 비교 모드에서 기간을 설정했을 때, **When** before/after를 확인하면, **Then** 해당 기간의 시작과 끝을 비교할 수 있다

---

### Edge Cases

- **보유 종목이 없는 계좌인 경우**: 드릴다운 시 어떻게 표시하는가? ("보유 종목 없음" 메시지)
- **비교 모드에서 같은 계좌를 선택한 경우**: 경고 메시지 또는 자동으로 다른 계좌 제안
- **그래프 데이터가 너무 많은 경우**: 줌 인/아웃이 어떻게 작동하는가? (스무스 스크롤, 데이터 포인트 간격)
- **모바일에서 드릴다운한 경우**: 화면이 어떻게 표시되는가? (전체 화면 모달 또는 페이지 이동)
- **비교 기간에 데이터가 없는 경우**: "해당 기간 데이터 없음" 메시지 또는 가장 가까운 데이터 사용

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 그래프 데이터 포인트에 마우스 오버 시 툴팁을 표시해야 한다
- **FR-002**: 시스템은 계좌 레전드 클릭으로 해당 계좌를 show/hide할 수 있어야 한다
- **FR-003**: 시스템은 마우스 휠로 그래프 줌 인/아웃을 지원해야 한다
- **FR-004**: 시스템은 계좌 카드 클릭 시 보유 종목 상세를 표시해야 한다
- **FR-005**: 시스템은 계좌 상세에서 종목별 변동 차트를 표시해야 한다
- **FR-006**: 시스템은 비교 모드에서 두 계좌를 선택하여 비교할 수 있어야 한다
- **FR-007**: 시스템은 비교 모드에서 기간 설정을 지원해야 한다
- **FR-008**: 시스템은 비교 결과에서 증감율을 계산하여 표시해야 한다

### Key Entities

- **툴팁**: 그래프 데이터 포인트의 상세 정보 (날짜, 계좌별 금액)
- **계좌 상세**: 보유 종목 리스트, 종목별 변동 차트
- **비교 모드**: 두 계좌 선택, 기간 설정, 증감율 계산
- **줌 컨트롤**: X축 범위 조절

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사용자의 90%가 그래프 인터랙션을 "직관적이다" 또는 "매우 직관적이다"고 평가한다
- **SC-002**: 사용자가 원하는 데이터를 찾는 데 걸리는 시간이 40% 이상 단축된다
- **SC-003**: 사용자의 75%가 드릴다운 기능을 "유용하다" 또는 "매우 유용하다"고 평가한다
- **SC-004**: 사용자의 70%가 비교 모드를 "도움이 된다" 또는 "매우 도움이 된다"고 평가한다
- **SC-005**: 모바일 사용자의 80%가 인터랙티브 기능을 "사용하기 쉽다"고 평가한다

## Assumptions

- 사용자는 마우스와 터치 모두를 사용한다
- 보유 종목 데이터는 계좌 데이터와 함께 저장된다고 가정한다
- 비교 모드는 최대 2개 계좌까지 비교 가능하다고 가정한다
- 줌 기능은 X축 범위 조절만 지원한다고 가정한다
- 드릴다운은 새 페이지가 아닌 모달 또는 확장 영역으로 표시한다고 가정한다
